# KidPoints (儿童积分管理系统)

面向家长的轻量、快捷儿童行为积分记录 Web 应用。支持日常光盘、学习、做家务正向加分，以及做错事扣分；支持自定义模板复用、即时微调分值、支持扣到负分、提供完整历史流水记录与云端存储。

## 核心特性一览

1. **家长专属极简看板**：直观展示当前总积分（支持负分警示与鼓励）、今日加分/扣分/净增汇总。
2. **快捷事项模板库**：
   - 加分习惯：🍽️ 光盘行动(+5)、🧸 整理房间(+3)、📖 专注阅读(+5)、✍️ 完成作业(+5)、🪥 刷牙洗脸(+2) 等；
   - 行为扣分：🍚 浪费食物(-3)、📱 超时看电视(-3)、⏰ 赖床磨蹭(-2)、😤 顶嘴打人(-5) 等；
   - 支持自定义新增、修改、排序、删除模板。
3. **分值即时调节**：点击任意模板即拉起微调面板，支持一键步进微调（如 `+1`、`+2`、`-5`）与自由输入，支持补充备注。
4. **自由记一笔**：针对偶发非模板事件，可随时随地手动记一笔。
5. **完整历史流水与撤销回滚**：
   - 记录变动前后的分值结余快照；
   - 支持按全部/加分/扣分筛选；
   - 支持误操作一键安全回滚，积分自动恢复。
6. **激励微动效与 PWA 原生体验**：
   - 获得加分时触发炫彩飘带粒子微动画；
   - 支持“添加到手机主屏幕”，获得免浏览器地址栏的全屏体验。
7. **云端全托管免运维**：
   - 本地基于 SQLite 零配置运行；
   - 云端无缝对接 Supabase (PostgreSQL) + Vercel / Zeabur，永久 0 费用。
